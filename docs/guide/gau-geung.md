# Gau Geung, the team mode

The usage guide for the team mode is an HTML page, so it can be read in a
browser or shared as one: [gau-geung.html](gau-geung.html). It covers what a
team and a seat are, how to define and boot one, the mode on `Alt+g`, how
seats talk and what holds them, handovers, what the screen says, editing in a
seat's worktree, import and export, the keys, and the fences mogeung keeps.

`draft` because the mode was built on 2026-10-10 and has not yet run a real
team on this machine; every row of
[pillar P](../product/roadmap.md)
is ⏳ until the first boot. The page follows
[feature 0051](../features/0051-gau-geung.md) and will be promoted to
`active` with it.
